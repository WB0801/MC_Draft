# 华仁周会司仪稿生成器

上传标准 Excel，确认讲话及颁奖流程，再生成和编辑司仪稿。网页为静态页面，Excel 在浏览器内解析。

## 使用

1. 在首页下载 `templates/MC_Draft_Template_v2.5.xlsx`。
2. 填写「周会设置」及「获奖资料」，保存并上传。纯讲话只需周会设置。
3. 确认流程、讲话人、部门顺序与颁奖人。
4. 生成后先检查成稿上方提醒，再核对姓名和奖项，复制或下载 TXT。

模板的「填写示例」使用虚构资料，并与正式输入工作表分开；示例不会自动进入成稿。网页仍兼容旧版模板。

草稿自动保存在当前浏览器的 localStorage，不跨浏览器或设备同步。清除浏览器资料会清除草稿；需要长期保留时请复制或下载。重新生成、替换文件或重新开始前会提醒保留修改；损坏或无法识别的文件不会清除原有草稿。浏览器禁用存储或空间不足时，页面会提示手动备份。

## 验证

使用 Node.js 18 或以上，无需安装 npm 依赖：

```sh
node --test tests/app.test.cjs
```

测试覆盖奖项排序、校外原顺序、班级及团体、纯讲话、可见错误、手动修改保护、刷新恢复、存储故障、损坏／空白文件和异步读取。测试中的名单均为虚构资料。

实际浏览器使用还需能加载页面引用的 SheetJS 读取组件；模板下载本身不依赖该组件。
